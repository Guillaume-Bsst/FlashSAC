# Labo Ant (jusqu'à E1) — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** une tâche de tracking d'une référence cinématique sur Ant (IsaacLab), la mesure de son infaisabilité (E0),
puis la comparaison chronométrée PPO (recette BeyondMimic) contre FlashSAC (E1).

**Architecture:** un paquet `ant_lab/` à côté de `flash_rl/`, sans toucher au code FlashSAC existant. Le calcul pur
(quaternions, bruit, références, rewards, faisabilité, métriques) est testé par pytest sans simulateur. Le code qui a
besoin d'IsaacSim (envs, enregistrement, lanceurs, évaluateur) est vérifié par des scripts `ant_lab/checks/` et des
runs courts. FlashSAC est lancé par `train.run()` de `train.py` après enregistrement de nos envs ; PPO par rsl_rl 3.0.1.
Un évaluateur unique note les checkpoints des deux algorithmes avec le même juge.

**Tech Stack:** IsaacSim 5.1, IsaacLab 2.3.0 (`DirectRLEnv`), rsl_rl 3.0.1, FlashSAC (ce dépôt), torch, numpy,
scipy (`nnls`, `gaussian_filter1d`), matplotlib, pytest 9.

**Spec:** `docs/superpowers/specs/2026-10-30-ant-tracking-lab-design.md`

## Global Constraints

- Exécution dans un worktree git sur une branche `ant-lab` créée depuis `main` (HEAD `87edc90`). Le worktree ne contient
  pas le travail G1 non commité de l'utilisateur : c'est voulu. Ne modifier ni `flash_rl/`, ni `train.py`, ni `configs/`.
  Le nouveau code va dans `ant_lab/`, `tests/ant_lab/`, `docs/ant_lab/` (plus deux lignes dans `.gitignore`).
- Python : `$HOME/.holosoma_deps/miniconda3/envs/hssim/bin/python`, toujours via `ant_lab/run.sh`, depuis la racine du
  worktree. Les scripts se lancent en module : `ant_lab/run.sh -m ant_lab.<module> ...`.
- Un seul IsaacSim par processus. pytest ne teste que du code pur, qui n'importe jamais `isaaclab` ni `omni`.
  Le code IsaacSim est vérifié par `ant_lab/checks/check_*.py` (code de sortie 0 = OK).
- Quaternions en (w, x, y, z) partout. Positions des références en repère « env-local » (monde − origine de l'env).
  Vitesses en repère monde.
- Fréquence de commande 60 Hz (sim 1/120 s, décimation 2) : une frame de référence par pas d'environnement.
- Toutes les valeurs numériques vivent dans `ant_lab/config.py` (Task 1). Aucune autre tâche ne les redéfinit.
- Sorties dans `results/ant_lab/` (ignoré par git). Ne jamais commiter de résultats, checkpoints ni logs.
- GPU partagé : au moment du plan, deux entraînements G1 de l'utilisateur occupaient 13,4 Go sur 16. Tout script
  IsaacSim appelle d'abord `check_gpu_free()` (≥ 4 Go libres) ; si ce n'est pas le cas, s'arrêter et prévenir
  l'utilisateur. Ne jamais tuer ses processus. Les runs chronométrés d'E1 exigent un GPU sans autre processus.
- Recettes figées ici, avant tout résultat : PPO = dict BeyondMimic de `holonew/OTRL/otrl/ppo_dict.py`,
  4096 envs ; FlashSAC = valeurs de `run_g1.sh` (batch 2048, n_step 3, 2 mises à jour par pas, AMP), 2048 envs,
  buffer 2 M.
- Journal `docs/ant_lab/JOURNAL.md` en français : l'hypothèse est écrite **avant** chaque expérience, le constat après.
- Messages de commit terminés par les lignes d'attribution de la session.

## Review Focus

1. **Convention de quaternion** (IsaacLab wxyz, PhysX xyzw) : un robot posé exactement sur la référence doit recevoir
   la reward maximale (5,0). → `check_tracking_env.py`, Task 8.
2. **Origines des envs** : même vérification sur l'env 0 et sur le dernier env (origine non nulle). → Task 8.

4. **Temps mesuré** : `elapsed = mtime du checkpoint − start_time`, avec `start_time` pris à la première ligne du

5. **GPU partagé pendant un run chronométré** : `run_e1.sh` refuse de démarrer si un autre processus utilise le GPU.
   → Task 13.

  class AdaptiveSampler:
      def __init__(self, num_frames: int, fps: float = FPS, kernel_size: int = 1, lam: float = 0.8,
                   uniform_ratio: float = 0.1, alpha: float = 0.001, device: str = "cpu"): ...
      num_bins: int                                   # int(num_frames // fps) + 1
      def record_failures(self, frames: torch.Tensor) -> None   # frames des épisodes terminés (pas les time-outs)
      def step(self) -> None                                   # une fois par pas d'env
      def probabilities(self) -> torch.Tensor                  # (num_bins,), somme 1
      def sample(self, n: int) -> torch.Tensor                 # (n,) long, dans [0, num_frames - 2]

  relative_body_targets(ref_anchor_pos, ref_anchor_quat, ref_body_pos, ref_body_quat,
                        robot_anchor_pos, robot_anchor_quat) -> tuple[Tensor, Tensor]   # (N,B,3), (N,B,4)
  anchor_obs(ref_anchor_pos, ref_anchor_quat, robot_anchor_pos, robot_anchor_quat) -> Tensor   # (N, 9)
  reward_terms(*, ref_anchor_pos, ref_anchor_quat, robot_anchor_pos, robot_anchor_quat, body_pos_rel,
               body_quat_rel, robot_body_pos, robot_body_quat, ref_body_lin_vel, ref_body_ang_vel,
               robot_body_lin_vel, robot_body_ang_vel, actions, prev_actions, joint_pos,
               joint_limits) -> dict[str, Tensor]        # clés = REWARD_WEIGHT, valeurs (N,) non pondérées
  total_reward(terms: dict[str, Tensor]) -> Tensor       # Σ REWARD_WEIGHT[k] · terms[k]
  termination_flags(*, ref_anchor_pos, ref_anchor_quat, robot_anchor_pos, robot_anchor_quat, body_pos_rel,
                    robot_body_pos, foot_ids: list[int]) -> Tensor   # bool (N,)

- `AdaptiveSampler` : portage de `AdaptiveTimestepsSampler` (`holosoma-otr-rl/src/holosoma/holosoma/managers/command/terms/wbt.py`,
  l. 893–930) : comptes d'échecs par bin d'environ 1 s, moyenne exponentielle `alpha`, `+ uniform_ratio / num_bins`,
  noyau non causal par `conv1d` avec remplissage `replicate`, normalisation. Tirage : bin par `multinomial`,
  `phase = (bin + U) / num_bins`, `frame = clamp(floor(phase·(num_frames − 1)), 0, num_frames − 2)`.
- `relative_body_targets` (BeyondMimic, même fichier l. 1555–1577) : `dq = yaw_quat(robot_q ⊗ ref_q*)` ;
  `ancre = robot_anchor_pos` avec son z remplacé par celui de `ref_anchor_pos` ;
  `body_pos_rel = ancre + quat_apply(dq, ref_body_pos − ref_anchor_pos)` ; `body_quat_rel = dq ⊗ ref_body_quat`.
- `anchor_obs` : `quat_apply_inverse(robot_q, ref_p − robot_p)` (3) puis
  `quat_to_mat(robot_q* ⊗ ref_q)[..., :, :2].reshape(N, 6)` (6).
- Termes (`holosoma/managers/reward/terms/wbt.py`) : `anchor_pos = exp(−‖Δp‖²/σ²)` ; `anchor_ori = exp(−angle²/σ²)` ;
  `body_pos`, `body_ori` : moyenne sur les corps contre `body_pos_rel`, `body_quat_rel` ; `body_lin_vel`,
  `body_ang_vel` : moyenne sur les corps contre les vitesses monde de la référence (non ré-ancrées) ;
  `action_rate = Σ(a − a_prev)²` ; `joint_limit = Σ[max(0, bas − q) + max(0, q − haut)]` avec
  bas/haut = milieu ∓ `SOFT_LIMIT_FACTOR` × demi-plage.
- Terminaison : `|z_ref − z_robot| > TERM["anchor_z"]` ou `|g_ref,z − g_robot,z| > TERM["anchor_grav_z"]` avec
  `g = quat_apply_inverse(q, (0, 0, −1))`, ou un pied de `foot_ids` avec `|z(body_pos_rel) − z(robot)| > TERM["foot_z"]`.

- `contact_residual`, à chaque frame : `M = Σm` ; `c = Σ m_i x_i / M` ; `p = Σ m_i v_i` ;

  (dt = 1/fps) ; torseur requis `w = [ṗ + (0, 0, M·g) ; L̇]`. Pour chaque contact actif k et chaque
  `d = normalize((0, 0, 1) + μ·e)`, `e ∈ {±x, ±y}`, une colonne `[d ; (p_k − c) × d]`.
  `λ = scipy.optimize.nnls(A, w)` ; `r = Aλ − w` ; `force_res = ‖r[:3]‖`, `torque_res = ‖r[3:]‖`.
  Aucun contact actif → `r = −w`.
